# ScrapeFun Client for macOS

> 最后更新：2026 年 7 月 26 日

ScrapeFun Client 是用于连接 ScrapeFun 综合媒体服务器的 macOS 桌面客户端，可浏览和播放电影、剧集，也可阅读服务器中的漫画；客户端不会在本机启动服务端。

## 下载与安装

1. 从 [Releases](https://github.com/HaoweiLi97/scrapefun-client-macos/releases/latest) 下载与你的 Mac 架构匹配的 DMG。
2. 打开 DMG，将 ScrapeFun Client 拖入“应用程序”。
3. 从“应用程序”启动客户端。

当前发布以 Apple Silicon 版本为主，具体支持架构以下载文件名为准。

## 连接服务器

首次打开客户端后，填写 ScrapeFun Server 地址，例如：

```text
http://192.168.1.10:8096
```

服务器可以来自 Docker、macOS Server 或 Windows Server。

## 更新

有新版本时，从 Releases 下载新的 DMG 并覆盖安装，服务器地址等客户端配置会保留。
